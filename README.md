# Constantino's Hotel — Landing Page

Landing page independente do Constantino's Hotel, construída apenas com HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` — estrutura da página
- `style.css` — identidade visual, responsividade e animações
- `script.js` — interações da interface e reserva demonstrativa com `localStorage`

## Execução local

Basta abrir `index.html` no navegador ou servir a pasta com qualquer servidor estático.

## Observação

Este repositório é independente do sistema interno do Constantino's Hotel e não possui backend, Node.js ou banco de dados.
